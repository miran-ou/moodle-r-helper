# Moodle+R Helper

立命館大学の Moodle+R の科目ページを便利にする、**非公式**の Chrome 拡張機能です。

> ⚠️ 大学や Moodle+R の公式のものではありません。利用は自己責任でお願いします。

## できること

- 科目ページに **シラバスへのリンク** を自動で追加
- 科目ページに **「シラバス情報」タブ** を追加し、次の内容を Moodle 上で確認可能
  - 開講年度・学期・曜日時限
  - 担当教員・キャンパス・教室
  - 授業の概要と方法
  - 成績評価の割合
- シラバスが見つからない場合は、シラバス検索ページへのリンクを表示

## インストール方法

Chrome ウェブストアでは公開していないため、手動で読み込みます。

1. このリポジトリをダウンロード（`Code` → `Download ZIP`）して展開する
2. Chrome で `chrome://extensions` を開く
3. 右上の **デベロッパー モード** をオンにする
4. **パッケージ化されていない拡張機能を読み込む** をクリック
5. 展開したフォルダ（`manifest.json` があるフォルダ）を選ぶ

Moodle+R の科目ページ（タイトルが `授業コード:授業名` の形式のページ）を開くと動作します。

## 仕組みとプライバシー

- 科目ページのタイトルから授業コードを読み取り、シラバスサイトで該当する科目を検索します。
- 検索や詳細の取得のため、**シラバスサイトを別タブ（非アクティブ）で一時的に開き**、取得後に自動で閉じます。
- 取得したシラバスの URL と詳細情報は、ブラウザ内の `chrome.storage.local` にのみ保存されます。
- **外部のサーバーへデータを送信することはありません。**
- 検索に失敗した科目は、3日間は再検索しません。
- 権限は `storage`（保存用）と、`lms.ritsumei.ac.jp` / `syllabus.ritsumei.ac.jp` へのアクセスのみです。

## デバッグ

動作ログを見たいときは、`content.js` と `background.js` の先頭にある次の行を変更します。

```js
const DEBUG = true;
```
